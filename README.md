# Лабораторная работа: Игра «Крестики-нолики» (Tic-Tac-Toe)

Учебный проект десктопного графического приложения для двух игроков, разработанный на языке Python с использованием стандартной библиотеки `tkinter`.

Выполнен в соответствии с требованиями на оценку **«Отлично»**:
- Архитектурный паттерн **MVC (Model-View-Controller)**.
- Адаптивная компоновка сетки (`grid` с `weight=1`).
- Современная темная цветовая тема (**Modern Dark Slate / Catppuccin**).
- Верхнее меню с пресетами и валидацией произвольного разрешения.
- Отказоустойчивая обработка исключений (`try-except`) без падений GUI.
- 100% соблюдение **PEP 8**, строгая типизация (`typing`) и русскоязычные docstrings.
- Полный комплект документации: `REPORT.md`, `REPORT.docx`, `ui_prototype.drawio`, `ui_prototype.svg`.

## Архитектура решения

1. **GameModel (`model.py`)**:
   - Предметная логика игры: дискретная матрица $3 \times 3$, проверка 8 выигрышных направлений ($O(1)$) и ничейного исхода.
   - Защита внутреннего состояния: геттеры `@property`, глубокое копирование матрицы `copy.deepcopy` (Defensive Copy).
   - Пользовательские исключения: `TicTacToeException`, `InvalidCoordinateError`, `CellOccupiedError`, `GameOverError`.
   - Неизменяемые записи ходов: `MoveRecord(frozen=True)`.

2. **TicTacToeApp (`main.py`)**:
   - Визуальные компоненты Tkinter с адаптивной сеткой (`rowconfigure`/`columnconfigure` с `weight=1`, `sticky="nsew"`).
   - Главное верхнее меню (`tkinter.Menu`):
     - **«Игра»**: Новая партия (`Ctrl+N`), Сброс счета (`Ctrl+R`), Выход (`Ctrl+Q`).
     - **«Настройки окна»**: Пресеты `400x500`, `600x700`, `800x900`, ввод произвольного размера через диалог с `try-except` валидацией, полноэкранный режим (`F11`/`Esc`).
     - **«Справка»**: Правила игры, О программе.
   - Подсистема логирования (`logging`) с трассировкой событий и ошибок.

## Инструкция по установке и запуску

### 1. Требования к окружению
- **Python**: версия 3.10 или выше (включая 3.11, 3.12, 3.13, 3.14).
- Библиотека `tkinter` (входит в стандартную поставку Python для Windows и macOS).
- Сторонние пакеты для запуска самой игры **не требуются**.

### 2. Запуск игры
```bash
python main.py
```

### 3. Запуск модульных тестов
```bash
python -m unittest test_model.py
```

### 4. Генерация отчета DOCX
```bash
python generate_docx.py
```

## Горячие клавиши

| Комбинация | Действие |
| :--- | :--- |
| `Ctrl + N` | Начать новую партию (поле очищается, ход переходит следующему игроку) |
| `Ctrl + R` | Сбросить турнирный счет матча (с подтверждением) |
| `Ctrl + Q` | Завершить работу приложения |
| `F11` | Включить / выключить полноэкранный режим |
| `Escape` | Выйти из полноэкранного режима |
