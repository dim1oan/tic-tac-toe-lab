# Лабораторная работа: Игра «Крестики-нолики» (Tic-Tac-Toe)

Учебный проект десктопного графического приложения для двух игроков, разработанный на языке Python с использованием стандартной графической библиотеки `tkinter`.

## Цель работы
Разработка настольной интерактивной игры «Крестики-нолики» для двух участников в соответствии с принципами объектно-ориентированного программирования (ООП), паттерном MVC (Model-View-Controller) и рекомендациями стандарта PEP 8.

## Архитектура проекта
- **GameModel (`model.py`)**: Модуль предметной логики (валидация координат, состояние матрицы 3×3, правила победы и ничьей, ведение статистики, история ходов, кастомная иерархия исключений `TicTacToeException`).
- **GameView / Controller**: Графический интерфейс на базе Tkinter с адаптивной сеткой `grid`, кастомной темной темой (Dark Theme) и динамическим масштабированием.
- **Top Menu**: Верхнее меню приложения для управления игрой, настройки геометрии окна и вызова справочной информации.

## Модульное тестирование
В проект включен набор модульных тестов `test_model.py`, проверяющий:
- Инициализацию пустого поля и стартового игрока.
- Корректность чередования ходов.
- Все 8 выигрышных конфигураций (3 строки, 3 столбца, 2 диагонали).
- Ситуацию ничьей при заполнении всех 9 клеток.
- Возбуждение исключений `CellOccupiedError`, `GameOverError`, `InvalidCoordinateError`.

Запуск тестов:
```bash
python -m unittest test_model.py
```

## Системные требования
- Python 3.10 или выше.
- Стандартная библиотека `tkinter` (входит в стандартную поставку Python для Windows/macOS).
- Дополнительные сторонние библиотеки для запуска игры не требуются.
